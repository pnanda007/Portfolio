## 🚀 Quick Start
To view locally:
```bash
# Clone the repository
git clone https://github.com/SamyakJ05/prashant-portfolio.git

# Open index.html directly or serve locally
open index.html
```

Or run with Python:
```bash
python3 -m http.server 8080
```
Then visit `http://localhost:8080`.
